# before: every call hits the API   from openai import OpenAI client = OpenAI()   def ask(prompt):     return client.chat.completions.create(...)     # after: cache handles the rest   from promptcache import cache   @cache def ask(prompt):     return client.chat.completions.create(...)   # exact match → cache hit 0ms $0.00 # ~same prompt → semantic hit 4ms $0.00 # new prompt → api call 820ms $0.003

how it works

Two-tier cache, one check

Every call runs through an exact match in SQLite, then a semantic search in ChromaDB. Hit either layer and the response is returned immediately — no network, no tokens, no cost. Miss both and the real call goes through and writes back.

integration

Decorator-first, nothing to rearchitect

@cache works on sync functions, async functions, and streaming responses. Pluggable embedder protocol — use SentenceTransformer locally or the OpenAI embedding API. No gateway, no proxy, no changed call signatures.

vs alternatives

GPTCache is abandoned. Gateways are overhead.

Every other caching layer either stopped shipping or requires you to route traffic through infrastructure you don't own. promptcache is a Python library. pip install promptcache. Your prompts stay on your machine.

MCP server

Your editor can see the cache too

A read-only MCP server ships with the library. Cursor and Claude Code can inspect hit rates, cost savings, and cache state without leaving the editor. The only LLM caching layer with native MCP support.
